# Muhasebe sözlüğü (sade Türkçe)

| Terim | Anlam |
|-------|--------|
| **Borç** | Hesabın sol tarafı. Varlık ve gider hesaplarında artış genelde borçtur. |
| **Alacak** | Hesabın sağ tarafı. Kaynak ve gelir hesaplarında artış genelde alacaktır. |
| **Çift taraflı kayıt** | Her işlemde toplam borç = toplam alacak. Dengelenmeyen fiş kesinleşmez. |
| **Muhasebe fişi / belge** | Bir işleme ait borç-alacak satırlarının toplandığı kayıt (yevmiye maddesi). |
| **Taslak** | Henüz deftere işlenmemiş fiş; değiştirilebilir. |
| **Kesinleştirme (Onaylı)** | Deftere işlenmiş fiş; satırlar doğrudan değiştirilemez. |
| **Ters kayıt** | Hatalı kesin fişi iptal etmek için ters borç/alacak ile yeni fiş. |
| **Hesap planı** | Şirketin kullandığı hesap listesi ve hiyerarşisi. |
| **Ana / Üst / Doğrudan hesap** | canias benzeri: Ana sınıf, ara kontrol, fiş yazılabilen yaprak hesap. |
| **Yevmiye** | Fişlerin tarih sırasıyla listesi. |
| **Büyük defter (kebir)** | Hesap bazında hareket dökümü. |
| **Mizan** | Hesapların borç/alacak toplamları ve bakiyeleri. |
| **Bilanço** | Belirli tarihte varlık = kaynak. |
| **Gelir tablosu** | Dönem kâr/zararı (gelir − gider). |
| **Cari hesap** | Müşteri/tedarikçi alt defteri; genel muhasebe kontrol hesabıyla mutabık olmalı. |
| **KDV indirilecek / hesaplanan** | Alışta indirilecek, satışta hesaplanan KDV. |
| **Tevkifat** | Verginin bir kısmının alıcı tarafından kesilip beyan edilmesi. |
| **Kur farkı** | Dövizli bakiyelerin dönem sonu kuruyla değerlenmesi sonucu. |
| **Mali yıl / dönem** | Kayıtların kapandığı zaman dilimi; kapalı döneme kayıt engellenir. |
| **Hesap belirleme kuralı** | “Satış faturası → hangi hesaplar?” eşlemesi. |
| **Idempotent muhasebeleştirme** | Aynı kaynak belge ikinci kez işlenince yeni fiş üretmeme. |
| **Fonksiyonel para birimi** | Şirketin defterlerini tuttuğu ana para (TR’de genelde TRY). |
| **Belge para birimi** | Fatura/fişin düzenlendiği para; kur ile fonksiyonel tutara çevrilir. |
| **Kontrol hesabı** | Alt defter (cari, banka) toplamlarının genel muhasebede toplandığı hesap. |
| **Mutabakat** | Alt defter bakiyesi ile kontrol hesabının eşitlenmesi. |
| **Açılış / kapanış fişi** | Dönem başı bakiyeleri ve dönem sonu kâr/zarar aktarımı. |
| **E-Rechnung (DE)** | Yapılandırılmış elektronik fatura (EN 16931); basit PDF sayılmaz. |
| **BTW (NL)** | Hollanda KDV’si; ICP AB içi bildirimlerle ilişkilidir. |
| **e-qaimə-faktura (AZ)** | Azerbaycan elektronik vergi faturası. |
